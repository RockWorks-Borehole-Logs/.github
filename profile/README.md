# RockWorks

> RockWorks keeps borehole logs, the subsurface model, and geologic maps on one 3D stratigraphy view so stacked holes stay tied to the same strata before the site meeting.

## Four Beats

1. **Name the project.** Give the RockWorks session a short title before you stack holes or draw maps.
2. **Pin the live holes.** Keep current borehole logs and the subsurface model on the RockWorks board and leave unused collars aside.
3. **Check the strata.** Read the RockWorks summary of 3D stratigraphy before you treat a unit as final.
4. **Close the loop.** Note which maps are ready so the next RockWorks visit does not start by hunting the borehole logs.

## First Questions

**Does RockWorks replace the printed site map?**  
No. RockWorks sits beside the logs, sections, and field sheets you already use.

**Can two geologists share one computer?**  
Yes. Each person keeps a separate RockWorks profile.

**Will RockWorks stay workable on an older office laptop?**  
Yes. RockWorks is meant to stay light during a normal site meeting.

**What should a new user try first?**  
One small RockWorks borehole set today, then the same subsurface model again tomorrow.

## Field Note

RockWorks is easier to trust when the project stays smaller than the folder it came from. A named session shows which site is active, the pins show which boreholes you will stack today, and the closing note tells the next person which borehole logs drive the subsurface model. That record is short on purpose: not a copy of every collar, only the path back to the strata that are still open.

The same loop fits a student log set, a client geology project, or a computer shared by two geologists. Open the last RockWorks session, confirm one unit, and leave the geologic maps easier to follow than you found them. Printed sheets stay where they are. RockWorks only holds the borehole logs, the 3D stratigraphy, and the handoff.

## One Real Pass

Pick a site that already has a name: a short drill fence, a quarry face, or a thin overburden pad. Open it in RockWorks, keep only those holes on the board, and read one stratigraphic unit you can point to. A pass is done when that unit stays tied to the borehole logs and the unused collars are no longer in the way. RockWorks does not need a full rebuild of the subsurface model before it is useful.

If the pass feels crowded, the project is too wide. Drop anything that belongs to a different site and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first collar to the last unit, with the summary still matching the geologic maps and 3D stratigraphy on the board.
